# Power BI Sales Dashboard Report

## 📌 Project Overview
This project is a Power BI dashboard designed to analyze and summarize sales performance. The report provides visual insights into total sales, profit, order volume, regional distribution, and sales trends over time.

## 📊 Key Metrics
- **Total Sales**: 3.49K
- **Total Profit**: 665.73
- **Total Orders**: 50

## 📈 Visualizations
- **KPI Cards**: Displaying Total Sales, Profit, and Orders
- **Bar Chart**: Sales distribution across different regions
- **Line Chart**: Sales trend by year, quarter, month, and day

## 🔍 Insights
- Noticeable sales fluctuations daily.
- Highest sales spike occurred in February 2024.
- Some regions consistently outperform others in sales.

## 🎯 Purpose
To help decision-makers quickly understand business performance and regional trends for strategic planning.

## 👨‍💻 Tools Used
- Power BI Desktop
- Data Visualization Components (DAX, Slicers, Charts)
